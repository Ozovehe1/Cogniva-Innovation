# Whiteboard handwriting assets

- `ems-casual-hand.json`: glyph strokes of **EMS Casual Hand**, a single-line (stroke) font by
  Sheldon B. Michaels, SVG conversion by Windell H. Oskay (Evil Mad Scientist Laboratories), a
  derivative of *Covered By Your Grace* by Kimberly Geswein. Licensed under the SIL Open Font
  License 1.1 (`OFL.txt`). Source: EMSCasualHand.svg from the Hershey/EMS SVG font collection
  (mirrored in svenhb/GRBL-Plotter, data/fonts/svg). Converted to JSON (strokes split per pen
  lift, coordinates rounded) for the board; no glyph shapes were changed.
- `public/whiteboard/hand.webp`, `hand-shadow.webp`: the hand holding the marker, a pre-rendered
  photographic sprite generated for GeniusMap (no third-party model), with its soft shadow.
